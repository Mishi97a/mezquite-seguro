# Mezquite Seguro

Módulo de entrenamiento interactivo y bilingüe (español / inglés) para cuadrillas de campo que cortan mezquite, aplican herbicida y operan maquinaria junto a paneles solares.

Interactive bilingual (Spanish / English) training module for field crews cutting mesquite, applying herbicide and operating machinery next to solar panels.

## Contenido

- Video de presentación con narración y subtítulos
- Formularios de seguridad de cada mañana
- EPP del día con un muñequito y cronómetro
- Carga de equipo, hielera y encargado por turno
- Manejo de equipo: motosierra, desbrozadora, minicargador, aireadora, herbicida y vehículos
- Durante la jornada: agua, pausas, comida y protección
- Salida del campo: "Regresa todo"
- Protocolo de accidentes, contacto con paneles y reporte de ubicación
- Evaluación con situaciones reales y glosario

Diseñado con Diseño Universal para el Aprendizaje (DUA) y andragogía.

Las respuestas se guardan solo en el navegador de cada persona. Las distancias, dosis e intervalos son referencias: mandan el manual del fabricante, la etiqueta del producto y las reglas del sitio.
